# Locked OS - MK-677 simplified tab

This build keeps the existing Locked OS features and simplifies the MK-677 tab to:

- Weekly plan: Monday-Friday, Saturday/Sunday off
- Current dose and cycle start controls
- Personal timing/schedule notes
- Basic monitoring only: date, weight, resting heart rate, notes
- Existing Supabase JSON-state persistence; no schema migration required

The previous MK-677 daily log, recent history, lab logging, and threshold UI were removed from the page.
