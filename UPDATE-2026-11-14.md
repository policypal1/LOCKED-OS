# Kill List, combined tabs, and gym rotation fix

## What changed

- Added **Kill List** near the end of the navigation, immediately before Admin.
  Add tasks or goals with a title, notes, priority, and an optional target date.
  Edit, complete, reopen, or delete items. Active, Completed, and All filters
  make it easy to see what remains. Items do not reset each day.
- Combined **GHK-Cu + CJC** into one main tab. Its two inner sections preserve
  the existing tracker forms, saved data, and reference content.
- Made Gym, the Looks checklist, and the rotation calendar use the same
  workout calculation. Explicitly completed Chest and Back sessions lead to
  Arms, followed by Legs + Abs. Refreshing or missing a day does not mark a
  workout complete.
- Clarified **Save draft**, **Complete workout**, and **Save changes**. A
  workout can be marked complete with unlogged sets left blank. An entered
  set still needs both weight and reps before completion.
- Added a workout date picker and **Workout you did** selector, plus
  **Edit / mark complete** in workout history, for correcting older records.
- Protected Kill List items and deletions from older synced snapshots, and
  kept unfinished forms intact during refreshes.

## Apply the replacement files

Replace these existing files in the repository root:

- `app.js`
- `index.html`
- `ghk-cu.js`
- `ghk-cu.css`

Add these files beside them:

- `kill-list.js`
- `kill-list.css`

Keep the filenames unchanged. The updated `index.html` loads all six files
with new cache versions. This update uses the existing saved-state format
and sync service; it needs no SQL migration or account setup.

After publishing through your usual deployment, reload LOCKED-OS. If the
old tab names remain, use a hard refresh. Existing logs and settings remain
in their current storage.

## If an earlier workout was saved only as a draft

Open **Gym**, choose the date you actually trained, select **Workout you
did**, and press **Complete workout**. You can also open the saved log and
choose **Edit / mark complete**. Do this for each real workout that was
never marked complete. The update recognizes older explicit completion
records but does not invent dates or promote every draft to a completed
session.

## Verification

Run the dependency-free regression tests with Node.js:

```sh
node --test tests/*.test.cjs
```

All 24 regression tests passed. They cover workout completion, drafts,
legacy records, historical corrections, repeated completion, rest days,
the 4 AM rollover, daylight saving time, save failures, concurrent Kill List
changes, deletions, and malformed records.

Full-page DOM interaction checks also passed for navigation, saved tracker
data, dirty forms, Kill List CRUD and reload, stale sync snapshots, gym date
and workout selection, and checklist completion. Those checks used synthetic
state and no live database connection. A Chromium visual check could not run
because this execution environment restricts browser socket creation.
